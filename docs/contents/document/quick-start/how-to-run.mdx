# How to Run

## Minimal SDK usage

```python
import asyncio

from agent_assembly import init_assembly


async def main() -> None:
    ctx = init_assembly(
        gateway_url="http://localhost:8080",
        api_key="required-api-key",
        agent_id="my-agent-001",
        mode="auto",
    )

    try:
        registration = await ctx.client.register_agent()
        policy_result = await ctx.client.check_policy_compliance("tool.call")
        print(registration)
        print(policy_result)
    finally:
        ctx.shutdown()


asyncio.run(main())
```
