# Agent Assembly Python SDK

The Agent Assembly Python SDK provides a lightweight client for connecting an agent to the governance gateway.

## Current Scope

This SDK currently includes:

- SDK bootstrap via `init_assembly(...)`
- A gateway client (`GatewayClient`) for registration and policy checks
- Typed data models under `agent_assembly.models`
- A base exception hierarchy under `agent_assembly.exceptions`

## Package Basics

- Package name: `agent-assembly`
- Python support: `>=3.12,<4.0`
- Source package: `agent_assembly/`
