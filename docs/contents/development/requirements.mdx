# Development Requirements

## Required

- Python `>=3.12,<4.0`
- `uv`
- Git

## Setup

```bash
git clone https://github.com/AI-agent-assembly/python-sdk.git
cd python-sdk
uv sync
```

## Optional

- `pre-commit` hooks
- Node.js and pnpm only if you are editing `docs/`
