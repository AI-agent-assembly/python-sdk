# Development Workflow

## 1. Sync branch

```bash
git fetch origin
git checkout master
git pull origin master
```

## 2. Create a feature branch

```bash
git checkout -b v0.0.0/AAASM-15/<topic>
```

## 3. Make and validate changes

```bash
uv run pytest
uv run ruff check .
uv run mypy agent_assembly
```

## 4. Commit and push

```bash
git add <files>
git commit -m "<GitEmoji message>"
git push origin <branch>
```

## 5. Open pull request

Open a PR to `master` and ensure CI checks are green.
