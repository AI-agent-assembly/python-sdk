# Type Checking with MyPy

The SDK ships with typed modules and a `py.typed` marker under `agent_assembly/`.

## Run MyPy

```bash
uv run mypy agent_assembly
```

## Type artifacts

- Marker file: `agent_assembly/py.typed`
- Shared aliases: `agent_assembly/types.py`

## Recommendation

Run MyPy locally before opening a PR to keep CI feedback fast.
