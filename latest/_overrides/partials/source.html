{#- Override of Material's partials/source.html (AAASM-3785). For any element marked `data-md-component="source"`, Material's bundled JS fetches GitHub "source facts" — stars, forks and the latest release tag — via the public GitHub API. This repository publishes no GitHub Releases, so the latest-release lookup (GET https://api.github.com/repos///releases/latest) returns 404 on every page load and surfaces as an uncaught console error. Dropping the `data-md-component="source"` marker keeps the repository link, icon and name but stops Material from issuing any unauthenticated GitHub API call, which removes the 404 (and the anonymous rate-limit exposure). The rest of the markup is identical to Material's generated partial. -#}
